# ToolRoute

## Search endpoint configuration

Execute `litescrape/search` with `{ "query": "your query", "max_results": 5 }` and a BYOK key. Set `LITESCRAPE_API_KEY` for direct adapter calls and health checks. Set `LITESCRAPE_BASE_URL` to override the API base URL. Support any Serper.dev-compatible endpoint (like litescrape.com, serpbase.dev, serpensapi.org, and others).
